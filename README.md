# Sales Follow-up MVP / 门店销售跟进助手

一个面向高客单、长决策链销售场景的 AI 跟进实验。

## 为什么做

最初假设：
线下门窗、全屋定制、装修等销售，在一次长时间客户沟通结束后，
大量客户需求、预算、顾虑、竞品和后续动作没有被完整记录。

希望验证：
能否将一次销售沟通自动转化为结构化客户上下文，
并进一步生成下一步跟进动作。

## 当前核心流程

1. 输入销售与客户的沟通内容
2. 提取客户需求、预算、顾虑、竞品、节点等上下文
3. 判断当前成交障碍和缺失信息
4. 生成可执行跟进卡
5. 沉淀到后续客户复盘与经验库

尚未完成验证：
- 长时间真实销售录音
- 门店噪音环境下的识别效果
- 多说话人区分

- 用户长期使用意愿

## 真实市场探索

已经尝试线下陌拜装修、全屋定制、防盗门等门店。

得到的部分反馈：
- 小夫妻店业务量不足
- 大型连锁已有总部培训和复盘体系
- 陌拜很难直接触达决策人
- 销售人员并不一定长期待在门店
- 因此产品正在从“门店完整录音”调整为更通用的“客户上下文 → 下一步销售动作”

## 我想验证的核心问题

不是“AI 能不能总结一段录音”，而是：

> 能否把真实销售沟通转化成优秀销售认可、并且愿意执行的下一步动作？
